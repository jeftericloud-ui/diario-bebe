# Contribuindo para Diário do Bebê

Obrigado por considerar contribuir! Abaixo estão algumas diretrizes para ajudar a tornar o processo fácil e previsível.

## Como começar

1. Fork o repositório.
2. Crie uma branch com um nome descritivo: `feature/minha-nova-funcionalidade` ou `fix/correcao-bug`.
3. Faça commits pequenos e com mensagens claras.
4. Abra um Pull Request descrevendo o que foi feito e por quê.

## Padrões de código

- HTML: busque manter a semântica correta (tags apropriadas: header, main, section, footer).
- CSS: prefira classes reutilizáveis e evite estilos inline quando possível.
- JS: organize funções, evite variáveis globais desnecessárias e comente trechos complexos.

## Reportando bugs

Abra uma issue com:
- Descrição do problema
- Passos para reproduzir
- Comportamento esperado
- Capturas de tela (se aplicável)

## Solicitações de funcionalidades

Abra uma issue descrevendo:
- O que você quer que seja adicionado
- Por que é útil
- Possível forma de implementação (opcional)

## Revisão de Pull Requests

Seja gentil e claro nas revisões. Forneça sugestões específicas e, quando possível, exemplos de código.

## Código de Conduta

Respeite todos os contribuidores. Não toleramos assédio. Mantenha as discussões profissionais e focadas no código.
